# DevPulse

DevPulse is a modern and responsive technology blog website created as a Week 3 web development project.

The website provides technology and software development articles in a clean and professional blog layout.

## Features

- Responsive navigation bar
- Homepage hero/banner section
- Six blog article cards
- Article categories
- Article dates and reading times
- Clickable blog cards
- Full article page
- Responsive design for mobile, tablet, and desktop
- Hover effects on blog cards and buttons
- About page
- Category pages
- Clean and professional user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Git
- GitHub
